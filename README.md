# Child Safety Solution (Hackathon Prototype)

A web prototype built for **Safe Childhood Through Innovation**, a 45-day design thinking hackathon on child safety, organised by Yi (CII) and hosted at Hindusthan College of Engineering and Technology, Coimbatore.

**Result:** Second Place (First Runner-Up)

## Live prototype

Link: https://ais-pre-ipmrczra27l3z6ivclcics-903261562079.asia-east1.run.app/

## Problem

Children who face abuse need protection, emotional support afterwards, and a safe, friendly environment.

## Our solution

A prototype that aims to:

- Protect children from abuse
- Help children recover and keep a steady mind after abuse
- Create a friendly environment for children
